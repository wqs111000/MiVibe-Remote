# Windows 可选配置

`WQS.json` 是 WQS 的个人按键预设，不是出厂默认配置，也不会自动启用。

## 在另一台 Windows 电脑使用

1. 安装本仓库新版 MiVibe Remote，完成遥控器蓝牙配对和 VB-CABLE 设置。
2. 打开客户端的「设置 → 配置文件 → 导入为自定义预设」，选择 `WQS.json`。
3. 检查载入的 WQS 按键与语音设置，点击「保存并应用」。已有预设仍保留。
4. 目标听写软件也需设置相同的 Ctrl + Shift + F9 快捷键和按住说话方式，并选用 CABLE Output 输入设备。先用电脑键盘确认该快捷键确实能打开听写，再用遥控器测试。

主要映射：语音 Ctrl + Shift + F9；菜单 Win + Tab；电源打开/切回 Codex；主页 Win + D；TV 切换窗口 Alt + Esc。

本文件不包含蓝牙地址、电脑路径、驱动安装状态、日志或账号信息。导入时保留当前电脑的设备配对信息。Windows 配置格式暂不支持直接导入 macOS 客户端。

修改之后，可以使用「配置文件 → 导出当前配置」保存一份新的命名配置。导出的是当前编辑内容；本机生效仍需「保存并应用」。便携格式支持快捷键、滚轮、打开 Codex 和切换预设，其他本机程序命令需在目标电脑单独设置。
